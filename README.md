# aivt-oop-java-group10
The Academic Integrity Violation Tracker (AIVT) is a Java-based console application designed to record and track students’ academic integrity violations. It allows users to record violations, classify offenses as Major or Minor, view a student’s violation history, update violation status, and display violation statistics. AIVT is our final badge exam project for Object-Oriented Programming (OOP) under the School of Computing at Holy Angel University (HAU) for the first semester.
